## ⚠️ FOR EDUCATIONAL PURPOSES ONLY

### Setup:
1. Set environment variables (BOT_TOKEN, ADMIN_ID, PHISHING_DOMAIN)
2. Deploy bot and server on Render
3. Start using `/start` on Telegram

### Structure:
- `/bot` - Telegram bot
- `/phishing-server` - Phishing page server
- `/shared` - Shared database

### OPSEC:

- Use VPN when testing
- Rotate domains frequently
